# Documentação do AiShot

> Ferramenta de captura de tela com IA para Windows.

O **AiShot** é um clone do Lightshot/prntscr voltado para IA. Captura uma região da tela, anota e **pergunta à IA sobre o print** — tudo num overlay in-place.
