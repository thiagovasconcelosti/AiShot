# Documentación de AiShot

> Herramienta de captura de pantalla con IA para Windows.

**AiShot** es un clon de Lightshot/prntscr orientado a IA. Captura una región de la pantalla, la anota y **pregunta a la IA sobre la captura** — todo en un overlay in situ.
